# CF Detailing — Sito

Landing page di c.f. detailing (Galliate, NO). Pagina statica in un solo file, senza build.

- `index.html`: pagina completa (stili, chatbot WhatsApp, galleria con lightbox, dati SEO).
- `img/`: logo e foto dei lavori.
- `favicon.svg`: icona del sito.

Colori, font, raggi e larghezza sono variabili CSS in `:root` all'inizio di `index.html`.
Il design system del brand è nel repository `cf-detailing-design-system`.
